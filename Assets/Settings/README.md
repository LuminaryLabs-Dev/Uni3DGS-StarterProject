# Generated URP settings

On first Unity import, `StarterProjectSetup` creates:
- `Uni3DGS-Renderer.asset`
- `Uni3DGS-URP.asset`

It also adds `Uni3DGSRendererFeature` and assigns the pipeline in Graphics/Quality settings.

They are generated instead of checked in because the current Uni3DGS package does not yet commit stable `.meta` GUIDs for its MonoBehaviour scripts.
