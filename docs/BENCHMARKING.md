# Benchmarking

`12-Performance` is a harness, not a marketing benchmark.

Record:
- Unity version
- Uni3DGS commit
- GPU / driver
- OS
- source format
- splat count
- load time
- FPS / frame time
- Unity allocated memory

Large datasets are deliberately not committed. Put local benchmark data under `Assets/Uni3DGS-Starter/TestData/Large/`.

Suggested tiers: 10K, 100K, 1M, 5M+.
